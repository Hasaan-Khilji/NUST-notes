# Vertical Asymptotic

An [[asymptotes|asymptote]] that is vertical is called a vertical asymptote.
A line $x = a$ is a vertical asymptote to  graph of $y=f(x)$  if
$$ 
\lim_{x \to a^+} f(x) = \pm \infty \\ \\
or \\ \\
\lim_{x \to a^-} f(x) = \pm \infty
$$
![[Vertical asymptote.svg]]
### Which functions?

All ratios of functions in which the value of the denominator function can be 0, have vertical asymptotes.

### How to find vertical asymptotes?

For general function $$f(x)= \frac{g(x)}{h(x)}$$where g(x) and h(x) can be any type of functions.  The vertical asymptotes are x = c.
For all values of c such that $h(c) = 0$.
